# Sales Dashboard

## 📊 Project Overview

This project is a Sales Dashboard created to analyze and visualize sales performance using a Superstore sales dataset.

The dashboard provides a clear view of sales trends, product-wise sales performance, total sales, total profit, and total orders.

## 🎯 Objective

The main objective of this project is to analyze sales data and present important business insights through an easy-to-understand dashboard.

## 🛠️ Tools Used

- LibreOffice Calc
- Spreadsheet Data Analysis
- Charts and Data Visualization
- Superstore Sales Dataset

## 📈 Dashboard Highlights

- Total Sales: ₹22,97,200.86
- Total Profit: ₹2,86,397.02
- Total Orders: 9,994
- Sales Trend Over Time
- Product-wise Sales Analysis

## 📌 Key Features

- Sales trend visualization
- Product-wise sales comparison
- Interactive-style dashboard presentation
- Business performance overview
- Data visualization using charts
